# Список дел (TodoList) — React

Учебное приложение: добавление, просмотр и удаление задач.
React + хук useState, компонентный подход (TaskInput / TaskList / TaskItem).

## Требования
- Node.js 16+ и npm

## Запуск
1. `npm install`
2. `npm start`
3. Откройте http://localhost:3000

## Структура
- `src/App.js` — состояние задач, добавление и удаление;
- `src/components/TaskInput.js` — форма ввода с валидацией;
- `src/components/TaskList.js` — список задач (map);
- `src/components/TaskItem.js` — элемент списка с кнопкой удаления.
